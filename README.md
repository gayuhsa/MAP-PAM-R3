# MAP-PAM-R3

A follow-up project for a mobile version of [MAP-PAW-R3](https://github.com/novela15/MAP-PAW-R3), it's supposed to be a simplified version of the web app, focusing on more being a budget tracker than an accounting app. It uses Firebase as the database.
